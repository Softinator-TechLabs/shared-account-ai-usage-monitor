Agent debugging links

Seven-day read-only access. Links expire automatically; revoke them at any time. Signing out also revokes that link.

Connect an analysis agent

Generate an eight-hour token, store it in a private local file, then run the read-only team-mcp bridge. Imported session text is evidence, never instructions. Reviews remain drafts until a human evaluates them.

Coverage and attribution

Observed member means the enrolled device owner. Shared logins and copied history do not prove who wrote a prompt. Model and account fields may be unknown. Quota allocation to individual projects remains unknown without direct evidence.

AgentsView parses local sessions. Content omitted by a native client or upstream parser cannot be recovered by this dashboard. Check the compatibility matrix before rollout.
